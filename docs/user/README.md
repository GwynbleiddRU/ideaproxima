# Documentation for users

For everyone who uses Ideaproxima: people proposing and developing ideas, scientists and engineers looking for
ideas and what they connect to, funders looking for what to back, evaluators, and moderators.

- [User guide](user-guide.md): what each thing on the platform is (ideas, revisions, stages, claims, evidence,
  arguments, evaluations, stances, involvement, relations, initiatives and outcomes), the exact rules it follows, how
  to read the numbers honestly, roles and moderation, and what is public. It ends with a glossary.

The guide describes the platform itself, so it holds for the web interface and any other client; its
[Finding your way](user-guide.md#finding-your-way) section maps each topic to a screen. To work with the API
directly, see the [API reference](../developer/api-reference.md).
